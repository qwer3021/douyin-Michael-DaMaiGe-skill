# 抖音主页 / 视频页浏览器操作参考

> 本参考仅供 AI 智能体阅读。Douyin 是动态页面, 下面所有定位都要以**语义目标 + 实读快照**为准, 不要依赖写死的 CSS 类名。

## 前提

- 抓取抖音必须使用**带浏览器 (aha_browser_use / computer_use_tool bu 平面) 的执行环境**。若当前环境导入 `aha_browser_use` 报 ModuleNotFoundError, 说明该环境无浏览器, 应切换到装有浏览器的环境 (例如本机 Windows 环境) 后再执行。
- 按 `browser-use-automation` 技能的操作规范走: `bu.navigate` → `bu.wait_for_load` → `bu.get_page_text` / `bu.snapshot` 观察 → 针对性动作 → 重新观察。

## 1. 进入博主主页

- 用 `scripts/resolve_douyin.py` 把分享短链解析成 `author_url` (https://www.douyin.com/user/<sec_uid>)。
- `bu.navigate(author_url)` 后 `bu.wait_for_load()`。页面可能因加载慢而报超时 — 超时后不要重复等, 直接再 `bu.get_page_text()` 读一次即可 (已成功跳转)。
- 页面顶部会弹出「扫码登录 / 验证码登录」弹层。这是**被动登录**: 正文 (博主信息 + 作品网格) 可读, 不需要登录。按浏览器技能规则, 不要关闭该弹层, 直接在它旁边读取内容即可。

## 2. 读取博主信息

页面文本通常包含: 昵称、关注/粉丝/获赞数、抖音号、IP属地、签名。示例:
```
Michael大麦哥
关注 906
粉丝 557.7万
获赞 1983.2万
抖音号：104274995
IP属地：上海
```

## 3. 提取作品网格 (前 N 个视频)

- 作品网格在「作品」标签下, 每张卡片是一个指向 `/video/<id>` 的链接 `a`, 卡片文本里就带**完整文案 (标题+描述+话题标签)** 和置顶标记。
- 用 `bu.get_page_text(max_chars=...)` 直接读整页文本, 或
  `bu.snapshot(within=bu.css('a[href*="/video/"]', match="all"), view="outline", max_chars=...)` 读取卡片锚点及其 href。
- 排序: 置顶视频在最前, 之后是最新作品。「前 N 个视频」默认按网格顺序取前 N 个 (含置顶); 若用户明确说「最新 N 个」则跳过置顶。
- 卡片文案可能被网格截断 (文本以 `…` 或截断符号结尾)。需要完整文案时打开对应视频页取全文。

## 4. 读取单个视频页的完整文案

- 打开 `https://www.douyin.com/video/<id>`。
- `bu.get_page_text()` 中标题 `<title>` 与正文区就是**完整文案**, 通常包括: 视频时长、完整描述正文、话题标签、发布时间、作者、播放/点赞等数据、评论区。
- 需要时把「发布时间」也记入知识库 (定位视频新旧)。

## 5. 常见问题

- **加载超时 / wait_for_load 报错**: 直接再读一次页面文本, 不要反复 wait。
- **被动登录弹层**: 内容可读就继续, 不关闭弹层。
- **截断文案**: 打开视频页取全文。
- **找不到某条视频**: 在「搜索 Ta 的作品」输入框检索关键词, 或确认是否在「合集 / 推荐」而非「作品」标签。
- **浏览器不可用**: 切换环境。抖音浏览需要浏览器环境。
